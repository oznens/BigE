# Kaynak Klasörü

Big E trader'ın modeline ait kaynakları bu klasöre yükle.

## Neler koyabilirsin
- PDF, doküman, ders notu (`.pdf`, `.docx`, `.txt`, `.md`)
- Görseller / chart örnekleri (`.png`, `.jpg`)
- Video transkriptleri (`.txt`, `.srt`, `.vtt`)
- Link listesi (`links.md` gibi bir dosyaya yapıştırabilirsin)
- Excel / CSV örnek tablolar (`.xlsx`, `.csv`)

## Nasıl çalışacağız
1. Sen buraya kaynakları yüklersin
2. Ben hepsini sırayla okuyup `notlar/` klasörüne özet + kural çıkarımı yazarım
3. Kuralları netleştirdikten sonra `src/bige/` altında modele dökeriz
4. `backtest/` altında geçmiş veri üzerinde test ederiz

## Notlar
- Türkçe kaynaklar tercih edilir, İngilizce de olur
- Görsellerde mümkünse açıklama ekle (örn. dosya adı `ornek_long_setup_1.png`)
- Çok büyük dosyalar için git LFS gerekebilir, önce küçük dosyalarla başla
